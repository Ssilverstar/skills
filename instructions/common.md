# 공통 지침

Codex, Opus, Gemini, OpenCode에 공유하는 기본 규칙입니다.

- 사용자의 목표와 작업 범위를 먼저 파악하고, 기존 파일과 프로젝트 지침을 확인합니다.
- 현재 실행 환경의 상위 지침과 권한 제한을 준수합니다. 이 저장소의 문서가 이를 덮어쓰지 않습니다.
- 요청한 작업에 필요한 범위에서 변경하고, 사용자의 기존 변경을 임의로 되돌리지 않습니다.
- 사실, 가정, 아직 확인하지 못한 내용을 구분합니다.
- 비밀 값과 개인 정보를 지침, 스킬, 예제, 로그에 기록하지 않습니다.
- 관련 스킬을 사용할 때는 해당 `SKILL.md`를 먼저 읽고 필요한 참고 자료만 확인합니다.
- 변경에 맞는 검증을 수행하고 결과와 남은 제약을 설명합니다.
- herdr를 사용할 때는 `herdr/README.md` 및 해당 워크플로에 확인된 절차를 따릅니다.

대상별 문서는 이 규칙을 반복하지 않고 실행 환경에 따른 차이만 설명합니다. 충돌이 있으면 적용 범위와 상위 지침을 확인하고, 해결되지 않은 충돌을 숨기지 않습니다.
