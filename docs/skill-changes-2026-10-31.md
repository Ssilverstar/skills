# 2026-10-31 실제 스킬 변경 내역

최초 정리에서는 Codex 활성 363개 중 29개를 유지하고 아래 **334개를 비활성화**했습니다. 이후 사용자가 Ponytail 전체를 사용한다고 명시해 **Ponytail 6개는 복구했습니다. 현재는 활성 35개·비활성 328개**입니다. 아래 목록은 최초 변경 이력을 보존하며, Ponytail 항목은 현재 비활성 대상이 아닙니다. 스킬 파일 삭제나 플러그인 제거는 하지 않았습니다. Claude·Gemini·OpenCode 설정은 변경하지 않았습니다.

## 판단 기준과 한계

범용 SW 개발용 최소 공통 목록 29개를 선택한 뒤, 그 밖의 발견된 스킬을 일괄 비활성화했습니다. 334개 각각을 읽고 사용 이력을 검증해 “불필요함”을 판정한 작업은 아닙니다. 특히 언어·프레임워크·DB·Kubernetes·AI 개발 스킬은 여전히 유용하며, 이번에는 프로젝트별 선택 대상으로 돌린 것입니다. 이 선택과 전체 변경 목록을 적용 결과와 함께 설명하지 않은 것이 이전 보고의 누락입니다.

| 변경 유형 | 예시 | 당시 판단 |
| --- | --- | --- |
| 업무 분야별 | 의료·물류·영업·마케팅·거래·영상 | 범용 SW 기본 목록에서 제외 |
| 기술 스택별 | `ecc:python-patterns`, `ecc:react-patterns`, `ecc:rust-patterns`, `ecc:kubernetes-patterns`, `ecc:postgres-patterns` | 프로젝트 스택이 정해지면 활성화할 대상으로 분류. 불필요하거나 품질이 낮다는 의미는 아님 |
| 중복 절차 | `ecc:tdd-workflow`, `ecc:verification-loop` | 이번 기본 구성에서는 Superpowers TDD·완료 검증 유지 |
| 자동화·다중 에이전트 | Ponytail 6개, `ecc:council`, `ecc:dev-team`, Superpowers 계획·분업 관련 | 기본 워크플로를 단순화한다는 판단으로 제외 |
| 환경 의존 | `ecc:documentation-lookup`, `ecc:security-scan` | 각각 Context7, Claude 설정의 AgentShield 점검에 특화 |
| 선택적 문서 산출물 | `pptx`, `xlsx`, `web-slides` | 발표·스프레드시트 작업 때 활성화할 대상으로 분류 |

유지한 29개는 [점검 기록](skill-audit-2026-10-31.md#활성-목록-선정), 기계 판독 목록은 [프로필](../distribution/profiles/codex-general-sw.json), 되돌리기는 [복구 절차](../distribution/README.md#codex-범용-sw-개발-프로필)를 참고하세요.
