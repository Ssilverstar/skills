# 작성 가이드

## 지침 추가

- 모든 대상에 적용하는 규칙은 `instructions/common.md`에 작성합니다.
- 특정 대상의 차이는 `instructions/agents/<target>.md`에 작성합니다.
- herdr 사용 규칙은 `herdr/README.md`, 작업별 절차는 `herdr/workflows/`에 작성합니다.
- 루트 진입점은 짧게 유지하고 원본 문서로 연결합니다.

## 스킬 추가

1. `skills/<skill-name>/` 디렉터리를 만듭니다.
2. `templates/skill/SKILL.md.template`을 새 디렉터리의 `SKILL.md`로 복사합니다.
3. 메타데이터와 본문의 안내 문구를 실제 내용으로 바꿉니다.
4. 필요한 경우에만 `references/`, `scripts/`, `assets/`를 추가합니다.
5. `skills/README.md`의 목록에 목적과 지원 대상을 등록합니다.

템플릿은 배포 스킬이 아니므로 `skills/` 밖에서 관리합니다.

## 변경 확인

- 문서 경로와 상대 링크가 실제 파일 또는 디렉터리를 가리키는지 확인합니다.
- 공통 지침과 대상별 지침이 중복되거나 충돌하지 않는지 확인합니다.
- 예제 명령과 스크립트는 대상 환경에서 검증하고, 검증하지 못한 내용은 표시합니다.
- 인증 정보와 개인 정보가 포함되지 않았는지 확인합니다.
- 구조 변경 시 루트 `README.md`와 관련 진입점을 함께 갱신합니다.
